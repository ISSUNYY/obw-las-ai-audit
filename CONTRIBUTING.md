# Como contribuir

Este é um projeto acadêmico em fase inicial. Contribuições devem preservar a
rastreabilidade dos resultados e a privacidade dos dados.

## Regras

- Abra uma issue descrevendo problema, hipótese e critério de aceitação.
- Não inclua LAS reais, coordenadas, identificadores de poços ou documentos de
  terceiros.
- Inclua testes sintéticos para mudanças de comportamento.
- Separe fatos calculados de interpretações produzidas por IA.
- Registre alterações de esquema e decisões metodológicas.
- Não inclua credenciais, tokens ou caminhos pessoais.

## Commits e pull requests

- Use commits pequenos e descritivos.
- Explique o impacto científico ou técnico da mudança.
- Informe os testes executados.
- Declare limitações conhecidas.
