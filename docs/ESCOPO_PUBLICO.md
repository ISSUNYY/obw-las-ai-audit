# Escopo público do projeto

## Proposta

O projeto desenvolverá um pipeline local para converter LAS em uma representação
JSON versionada, calcular métricas de qualidade e usar uma IA local para explicar
somente conclusões sustentadas por evidências verificáveis.

## Piloto

O piloto termina quando demonstrar:

1. preservação estrutural e numérica entre LAS e JSON;
2. detecção determinística de problemas de qualidade;
3. geração de explicações locais em formato estruturado;
4. rejeição automática de afirmações sem evidência;
5. reprodução dos resultados a partir das versões registradas.

## Fora do piloto

- classificação completa de litofácies;
- preenchimento automático de valores ausentes;
- alteração dos arquivos originais;
- publicação dos dados privados;
- substituição da interpretação especializada.

## Evoluções possíveis

- classificação de eletrofácies com validação por poço;
- estimativa calibrada de incerteza e classe indeterminada;
- incorporação de continuidade vertical;
- agrupamento exploratório;
- física de rochas;
- interface gráfica e processamento em lote.
